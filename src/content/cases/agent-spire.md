## 把概念变成一局游戏

Agent 尖塔是一款像素风单人卡牌爬塔游戏。十章九十层的路线围绕 Agent Loop、上下文、RAG、工具与 MCP、评估和多 Agent 协作展开；玩家在规划路线、应对敌人意图和构筑卡组的过程中完成知识练习。

三个角色提供不同构筑方向，卡牌、遗物、药水与章节事件构成游戏系统。这里的数值和胜负属于游戏机制，不代表模型能力。

## 两种难度与可回看的解释

入门模式使用生活化情境题，先解释概念，再让玩家作出判断；地狱模式使用 Python 工程题，练习代码追踪、故障排查与方案取舍。提示和答题解析帮助玩家理解结果，图鉴可以独立练习。

自动通关与回归检查用于确认流程可达，并不能证明人类玩家的胜率或学习效果。

## 在浏览器中游玩

游戏在浏览器本地运行，不调用大模型，不需要账号或 API 密钥。在线版可以直接打开，下载版支持离线游玩；存档按浏览器和站点分别保存，两个版本之间不会自动同步。

知识来源是李博杰《深入理解 AI Agent：设计原理与工程实践》v2.0。项目提供章节对应关系，不分发教材 PDF，也没有把全书每个小节都游戏化。
