你好，我是李在希。

All in on AI Agents.

从自己的问题开始。

电子科技大学在读，关注 Agent 的执行流程、上下文管理与可验证交付。通过真实使用中的问题，练习把模型能力变成可靠、顺手的产品。

我在电子科技大学学习电子信息科学与技术，预计于 2029 年秋季毕业，目前在成都。Learn-Agent 源于我的编程学习需求：先帮我跨过眼前的卡点，再在后台留下可以回看的知识。

后来，我通过 PiLoop 探索主动执行与偏好记忆，通过 Legion 探索多个 Agent 的分工、独立验收与可恢复执行。项目对我而言，也是把抽象判断变成可以运行和检查的过程。

我在意的产品与工程。

主动承担可以自动完成的工作，让用户专注于真正需要判断的选择。记录来源，允许修改，在失败时说清楚发生了什么。速度有价值，可验证的交付同样重要。

这些判断来自个人学习和项目实践。我希望在真实团队里继续理解业务约束、协作成本与运行中的失败，也会区分已经验证的事实和仍待检验的想法。

Agent Harness上下文与记忆工具接口独立验证用户体验

寻找实习机会。

希望参与 Agent Harness 工程、执行流程、上下文管理与评估相关工作。可长期实习、随时到岗，接受北京、上海、杭州、深圳、成都的异地线下实习。
