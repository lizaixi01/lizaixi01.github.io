自治边界2026.09.09

Agent 的优势，首先来自问题所处的环境

当目标可以明确表达、尝试可以低成本重来、结果可以独立验证，持续搜索才有机会转化为可靠的进展。从代码到芯片仿真，这比职业名称更能解释自治的边界。

验证与协作2026.09.09

多 Agent 协作，应当建立在可拒绝的交接上

Goal-Driven 决定工作围绕什么持续，Zero-Trust 决定什么产物值得接收。角色更多、讨论更长，都不能代替独立验证。

自治边界2026.09.11

开放工程中，人的工作是不断确定目标

判断人的介入是否必要，先区分目标尚未形成、信息尚未取得与已有约束在执行中丢失。上下文工程可以减少后两类负担，却不能替组织自动形成承诺。

形式化数学2026.09.09

形式化数学：允许探索失败，要求结论可验证

证明搜索与证明检查之间的差异，使数学成为长期 Agent 回路值得关注的方向。但形式正确、命题正确、结果新颖与研究价值，仍是四个不同问题。
